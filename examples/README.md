## What these examples have in common

Each one contradicts its own headline number somewhere. That isn't a stylistic tic — it's
the point. A crawler's top finding was wrong. An impressions chart went up while traffic
went nowhere. A striking-distance list pointed the wrong way.

Tools produce findings. The work is deciding which findings are real, and every example
here states what it could *not* see alongside what it found.
